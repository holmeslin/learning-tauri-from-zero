# 選單、系統匣與快捷鍵

桌面 App 有幾個入口不在網頁裡：螢幕或視窗上方的選單、按右鍵跳出來的選單、藏在角落的系統匣圖示、不用切換視窗就能叫醒 App 的全域快捷鍵。前端的 `@tauri-apps/api/menu`、`@tauri-apps/api/tray` 其實也能建選單與系統匣，但這一章一律在 Rust 這一側建：選了項目之後要做的事，大多是結束 App、叫出視窗，Rust 這一側直接就能做，不用繞到前端再回來。這些功能只有桌面版有，手機沒有，第 18 章會正式介紹。

桌面 App 還有一個前端碰不到的問題：使用者重複啟動，不該冒出第二個一模一樣的行程。這一章把這些零件一個一個學會。把它們組起來的系統匣小工具，第 13 章會正式介紹。

# 前端速成

Tauri App 的畫面是網頁，所以在寫 Tauri 之前，得先會一點前端：網頁怎麼搭、怎麼排版、TypeScript 怎麼寫，還有怎麼用程式改畫面、回應使用者的操作。這一章把這些補到「夠用」的程度，遇到 Rust 已經教過的概念，就拿 Rust 來對照，不重新教程式設計。

這一章只在第 1 章建好的專案裡改 `index.html`、`src/main.ts` 和 `src/styles.css`，完全不碰 `src-tauri`，也不呼叫 `invoke`，不用任何框架，只用瀏覽器本來就有的功能。每一集都從第 1 章的專案出發：貼出來的檔案是完整內容，整個換掉就好，沒貼出來的檔案維持範本原樣。

# GitHub Actions 跨平台發佈

第 15 章說過，每種安裝檔都只能在自己的平台上打：`.dmg` 要在 Mac，MSI 要在 Windows，AppImage、deb、rpm 要在 Linux。要發佈給三個平台的使用者，你得有三台機器，每發一版就各跑一遍。這一章把這件事交給 GitHub Actions：你推上去，GitHub 替你開出三種平台的機器，各自打包，成品收在同一個地方。

接著把它跟前兩章接起來：在這些機器上替更新檔簽章，把安裝檔和更新資訊檔一起放上 GitHub Release，讓第 16 章的自動更新有地方取檔。程式碼簽章的憑證還是要付費，這一章只講它在 CI 裡怎麼接，不依賴真的憑證。

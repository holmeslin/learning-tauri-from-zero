# 自動更新與程式碼簽章

App 發給別人之後，你還是會修 bug、加功能。總不能請每個人重新下載、重新安裝。自動更新（auto update）讓 App 自己去問「有沒有新版」，有的話下載、換掉自己、重新啟動。這一章先把這條路從頭走通，用一個會真的從 1.0.0 更新到 1.1.0 的 App 當例子。

更新檔是從網路下載來的，得確認它真的是你發的，所以 Tauri 要求每個更新檔都要簽章，用的是你自己產生的一對金鑰，不用花錢。另一種簽章是程式碼簽章（code signing）：作業系統用它判斷一個 App 可不可信，決定使用者第一次打開時會不會被擋。這部分要付費的憑證（certificate），這章只說明流程，範例不依賴真的憑證。

# 行動裝置

Tauri 2 除了桌面，也能把同一個專案做成 Android 與 iOS 的 App：Rust 程式碼編成手機用的函式庫，畫面一樣交給 WebView。這很重要，因為你不用為手機另寫一套 App。前面各章的前端與 Rust 大多原封不動就能用，要多學的是開發工具、專案怎麼產生，以及桌面與手機在哪些地方不一樣。這一章會把第 11 章的待辦清單搬上手機，最後打包成 APK、AAB 與 IPA。

寫這一章的電腦沒有 Android 與 iOS 的開發工具，所以行動裝置的指令我們都沒有實際跑過，書中也不貼它們的輸出，內容依 Tauri 官方文件與原始碼查證。Rust 與 TypeScript 的程式碼照樣經過檢查，但檢查程式只驗證桌面的編譯。

# 行動裝置

Tauri 2 除了桌面，也能把同一個專案做成 Android 與 iOS 的 App：Rust 程式碼編成手機用的函式庫，畫面一樣交給 WebView。這一章從要裝的工具開始，產生 Android 與 iOS 的專案、在模擬器上執行，看桌面與行動在程式碼上差在哪裡，再把第 11 章的待辦清單搬上手機，最後打包成 APK、AAB 與 IPA。

寫這一章的電腦沒有 Android 與 iOS 的開發工具，所以行動裝置的指令我們都沒有實際跑過，書中也不貼它們的輸出，內容依 Tauri 官方文件與原始碼查證。Rust 與 TypeScript 的程式碼照樣經過檢查，但檢查程式只驗證桌面的編譯。

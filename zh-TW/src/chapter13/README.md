# 實戰：系統匣小工具

這一章做一個住在系統匣的小工具「快速便條」：平常看不到視窗，按一個全域快捷鍵，一個小視窗跳出來，隨手記幾個字，再按一次就收起來。系統匣的選單可以開設定視窗、結束 App；設定視窗能改字型大小，也能決定要不要開機自動啟動。

前面三章的主角都是視窗，這一章反過來：沒有主視窗，系統匣與快捷鍵才是入口。幾乎所有的程式都在 Rust 這一側，前端只負責畫兩個很薄的畫面。這一章會用到視窗（第 6 章）、store plugin（第 7 章）、系統匣與全域快捷鍵（第 8 章），多學兩件事：讓 App 啟動時不顯示視窗、關掉視窗卻不結束 App（第 2 集），以及開機自動啟動（第 6 集）。
